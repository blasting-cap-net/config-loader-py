# config-loader-py

Deterministic layered configuration loader supporting hierarchical environment overrides.

[![CI](https://github.com/placeholder/config-loader-py/actions/workflows/ci.yml/badge.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A lightweight, high-reliability Python utility package developed for cloud-native microservices and pipeline health processing.

## Quickstart
```bash
pip install -r requirements.txt
python config_loader_py/core.py
```

## Running Tests
```bash
python -m unittest discover tests
```
